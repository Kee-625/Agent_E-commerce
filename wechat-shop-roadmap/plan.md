# Report Plan

## Meta
- **Type**: 运营战略报告（决策型）
- **Topic**: 微信小店「腰腹热敷带」店铺在主营类目为运动户外的错配下，未来 12 个月如何发展
- **Audience**: 店铺店主/运营负责人
- **Language**: 中文

## Design System

### Palette
- **Background** (`--bg`): `#FFFFFF`
- **Surface** (`--bg2`): `#F4F5F2`
- **Text** (`--ink`): `#1D2226`
- **Text muted** (`--muted`): `#656B68`
- **Border** (`--rule`): `#E2E4DF`
- **Accent** (`--accent`): `#FFD633`（仅作填充/图形，不作正文文字）
- **Accent 2** (`--accent2`): `#C84E43`（语义信号，可作文字）

### Typography
- **Heading font**: Outfit Bold + PingFang SC / Microsoft YaHei 回退
- **Body font**: Work Sans + PingFang SC / Microsoft YaHei 回退
- **Mono font**: Geist Mono
- **Heading style**: 粗体、左对齐、无字间距
- **Body size**: 17px / 行高 1.7

### Layout
- **Max width**: 1040px（正文列 760–820px，证据区全宽）
- **Page structure**: Hybrid Brief——宽幅结论区 + 全宽决策画布 + 可读正文
- **Section spacing**: 5rem 分段
- **Header style**: 左对齐报头，无外框

### Components
- **Section headings (h2)**: 大号编号 + 标题，无左侧色条
- **Subsection headings (h3)**: 同色粗体
- **Callouts**: 全宽背景带或反白块，禁止左侧竖线卡片
- **Cards**: 使用留白与分隔线，最多一层圆角卡
- **Tables**: 全宽、仅横线、无斑马纹
- **Dividers**: 1px 发丝线

### Visual personality
克制的运营工作台质感：白底、纸感中性色、黄色作高亮块、珊瑚红作唯一语义信号。

## Structure
1. 结论先行（Inverted Verdict）— 换主线，不换货；先过合规闸门
2. 诊断：类目—人群—内容三方错位
3. 平台硬约束（三条规则底线）
4. 三条路径对比（全宽表）
5. 推荐路径与改选条件
6. 12 个月跑道（三阶段 + 闸门）
7. 商品矩阵与内容—私域打法
8. 风险闸门与合规清单
9. 待确认与补数清单
10. 来源

## Key Arguments / Thesis
- 热敷带的购买动机是「身体舒缓」，不是「运动表现」；挂在运动户外会造成内容人群、搜索词、活动场全部错位
- 微信小店的类目决定的是资格（能否挂车、能否进优选联盟、能否报名活动），不是流量；资格错会直接封顶增长
- 改类目是一次性成本，拖一年等于用错误定位持续烧内容与投流预算
- 推荐「健康个护主线」，但保留明确的改选条件（现有成交与内容资产偏运动时改走运动户外）
