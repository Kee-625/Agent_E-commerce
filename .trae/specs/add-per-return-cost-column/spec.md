# 单次退货成本列 Spec

## Why
现有退货成本公式把“退货一次 3 元”写死为 `退货率 × 3`，只适用于护腰带。店铺后续会加入其他商品，退货一次的成本各不相同（可能 2 元、5 元），写死会导致净利算错。

## What Changes
- 在 L 列（退货率）之后插入 M 列「单次退货成本」，逐行手动填写
- 退货成本公式由 `退货率 × 3` 改为 `退货率 × 单次退货成本`
- 原 M 退货成本→N、N 所得税率→O、O 所得税→P、P 其他成本→Q、Q 单件净利→R、R 净利率→S
- 护腰带三行「单次退货成本」填 3 元
- 新列 M 归入手动填写色（浅黄），N 退货成本仍为自动计算色（浅蓝）

**BREAKING**：L 列右侧所有列号右移一位。

## Impact
- Affected specs: `add-sku-cost-profit-columns`（退货成本公式变更）、`add-image-column-and-color-code`（列结构由 A:R 变为 A:S）
- Affected code: 无业务代码；使用腾讯文档 sheet-mcp（insert_dimension / set_range_value / set_cell_style）
- 涉及资源：文档 file_id `HGHIXNuwfGoa`，子表 `商品管理` sheet_id `BB08J2`

## ADDED Requirements

### Requirement: 列结构
「商品管理」SHALL 在 L 退货率之后增加 M 单次退货成本，完整列序为：

| 列 | 字段 | 属性 |
|---|---|---|
| A | 商品图片 | 手填 |
| B | 产品简称 | 手填 |
| C | 产品ID | 手填 |
| D | SKU名称 | 手填 |
| E | 最终售卖价 | 手填 |
| F | 商品成本 | 手填 |
| G | 运费险 | 手填 |
| H | 达人佣金率 | 手填 |
| I | 达人佣金 | 自动 |
| J | 平台扣点率 | 手填（预置 0.05） |
| K | 平台扣点 | 自动 |
| L | 退货率 | 手填 |
| M | 单次退货成本 | 手填（新增） |
| N | 退货成本 | 自动 |
| O | 所得税率 | 手填（预置 0.05） |
| P | 所得税 | 自动 |
| Q | 其他成本 | 手填 |
| R | 单件净利 | 自动 |
| S | 净利率 | 自动 |

#### Scenario: 查看退货相关列
- **WHEN** 用户打开「商品管理」
- **THEN** L 退货率、M 单次退货成本、N 退货成本三列相邻排列

### Requirement: 退货成本计算
退货成本 SHALL 按每行的退货率与单次退货成本相乘得出，不再写死 3 元。

- N 列公式：`=IF($E{r}="","",$L{r}*$M{r})`
- 修订后 P 所得税：`=IF($E{r}="","",($E{r}-$F{r}-$G{r}-$I{r}-$K{r}-$N{r}-$Q{r})*$O{r})`
- 修订后 R 单件净利：`=IF($E{r}="","",$E{r}-$F{r}-$G{r}-$I{r}-$K{r}-$N{r}-$Q{r}-$P{r})`
- 修订后 S 净利率：`=IF($E{r}="","",IFERROR($R{r}/$E{r},0))`

#### Scenario: 护腰带一条装
- **WHEN** 售价 21、退货率 10%、单次退货成本 3
- **THEN** 退货成本为 0.3，与修改前一致，净利仍为 4.7975

#### Scenario: 新商品单次退货成本 5 元
- **WHEN** 某商品退货率 10%、单次退货成本 5
- **THEN** 退货成本为 0.5，按该商品自己的数值计算，不受护腰带影响

### Requirement: 颜色分区同步
新列 SHALL 纳入既有颜色体系（第 1–50 行）。

- M 单次退货成本 SHALL 为浅黄 `#FFF2CC`（需手填）
- N 退货成本 SHALL 保持浅蓝 `#CFE2F3`（自动算）
- O 所得税率、Q 其他成本浅黄；P 所得税、R 单件净利、S 净利率浅蓝

#### Scenario: 新增商品时识别列色
- **WHEN** 用户新增一行商品
- **THEN** M 列显示黄底，提示需填写单次退货成本

### Requirement: 既有数据保留
插入列 SHALL 不丢失任何数据：B:D 商品信息、J/O 费率、I/K/N/P/R/S 公式、颜色均保留。

#### Scenario: 插入后核对
- **WHEN** 插入与改写完成
- **THEN** 第 2–4 行商品信息完整，J、O 仍为 0.05，第 2 行净利仍为 4.7975

## MODIFIED Requirements
### Requirement: 退货成本公式
原「退货成本 = 退货率 × 3」被替换为「退货成本 = 退货率 × 单次退货成本」，单次退货成本按行填写，允许不同商品取不同值。

## REMOVED Requirements
无。
